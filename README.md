#漳州市乡镇老龄化空间统计分析代码
## 运行环境
R 4.0 以上
## 依赖包
readxl, writexl, sf, spdep, dplyr
## 文件说明
entropy.R：熵值法综合得分测算（附录D）
esda.R：空间权重矩阵、全局 Moran's I、LISA、Getis-Ord 冷热点分析（附录E）
## 数据说明（重要）
因原始数据涉及保密要求，本仓库不提供数据文件。
如需复现，请依据第七次全国人口普查乡镇级数据自行整理，数据格式要求如下：
熵值法数据：需包含区县、乡镇街道名称、老年人口比重、老年抚养比、少儿抚养比、少年儿童比重、劳动年龄人口占比。
ESDA数据：需包含区县、乡镇街道名称、综合得分，以及乡镇矢量边界 shp 文件。
## 运行说明
1. 用 RStudio 打开 `entropy.R` 或 `esda.R`。
2. 将代码中的文件路径修改为您本地的实际路径。
3. 运行代码，结果将输出到当前目录。
